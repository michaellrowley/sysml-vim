# Configuration

## Vim globals

- `g:sysml_backend_cmd` (default: `sysml`)
- `g:sysml_default_view` (default: `composition`)

## Environment variables

- `SYSML_PILOT_COMMAND`: optional command path used by `sysml adapter` for official tooling integration.

## Health report

Run `:SysmlHealth` or `sysml health --path .`.
